# LocalGPT 0.1.0

发布日期：2026-11-09

[English](https://github.com/ThineLord/localgpt/blob/v0.1.0/docs/releases/0.1.0.md) · [简体中文](https://github.com/ThineLord/localgpt/blob/v0.1.0/docs/releases/0.1.0.zh-CN.md)

## 本次更新

这是 LocalGPT 首次采用版本管理的源码发布，基于已有主分支应用 `d4520a3`。更新包括简洁的项目首页、独立中英文用户／agent 指南、历史文档归档和明确的发布流程。

基线已包含本地对话、ComfyUI 图像生成／编辑、项目、保存的记忆、图库、草稿、中英文和外观设置。本次不修改运行行为。

## 版本管理

`VERSION.txt` 是源码版本的唯一来源。后续发布同步更新 changelog 和中英文版本说明，由原生 subagent 独立 review 并合并，再在已审查的合并提交上建立不可重定向的 `v主版本.次版本.修订版本` 标签。Codex 负责组织；流程不调用 bots 或云端 agent。

## 兼容与升级

运行源码仍在 `work/chat-sidebar/`。现有启动器、API、数据库路径、浏览器存储、本地模型配置和数据目录不变。本次仅整理文档，无需数据库迁移或服务重启。发布源码不会自动更新已有安装。

新 checkout 见[用户指南](https://github.com/ThineLord/localgpt/blob/v0.1.0/docs/user-guide.zh-CN.md)。已有 checkout 获取／切换标签前先检查本地修改，不要以日常整理为由切换运行中服务的源码。

## 验证与限制

发布准备检查版本一致性、文档链接、页面构建一致性、暂存源码和可达历史；PR 记录精确 head 对应的本地检查和 review。源码发布与部署分开，不代表完成了新的真实模型或生产验收。

待验收的 [PR #26](https://github.com/ThineLord/localgpt/pull/26)（包括中断生成恢复）不在本次范围内，保留其原有验收条件。模型和外部本地服务不随仓库分发。历史验收文档仅供追溯。
