# LocalGPT 0.2.1

[English release notes](https://github.com/ThineLord/localgpt/blob/v0.2.1/docs/releases/0.2.1.md) · [更新历史](https://github.com/ThineLord/localgpt/blob/v0.2.1/CHANGELOG.md)

发布日期：2026-11-09。本次为运行源码补丁；发布不会自动部署已有安装，也不包含模型。

## 修复内容

- **停止提示跟随任务结束。** 对话或图片任务到达终态时，清除等待提示；迟到的 HTTP 确认不会把提示重新显示。切换对话、新任务和其他错误提示保持各自状态。保留部分回答、图片中止记录以及用户显式重试行为。
- **慢启动保持待就绪状态。** 启动器默认等待就绪最多 120 秒；进程仍存活但需要更久时，明确提示仍在后台启动，不误报失败或宣称已经运行。再次执行启动器会检查同一进程。服务继承每端口 POSIX 文件锁，即使原启动器退出，也能防止尚未绑定端口时启动重复进程。`--wait-seconds` 只调整前台等待预算，不取消后台启动。真实进程退出、端口被占用、错误服务或不同 checkout 仍会报错；确认界面身份和就绪之后才打开浏览器。

## 验证

当前合成套件覆盖停止确认迟到、终态提示清理和其他停止错误，并包含 12 项启动器回归，使用临时目录、隔离进程及模拟时钟。覆盖超过旧 15 秒窗口后就绪、后台等待输出、并发/重复启动、父启动器退出、子进程失败及其他服务保护。使用旧实现运行负向对照可复现两个问题。

新虚拟环境运行 `.venv/bin/python tools/validate.py --setup`，完成安装后可省略 `--setup`。发布验收在准确合并提交上执行完整套件。本地真实模型回归属于单独的安装验收；合成通过不等于模型质量、生图时延、断电恢复或系统登录自启已通过。本次不配置付费 CI 或云端推理。

## 升级

相对 0.2.0，不改变应用数据结构、模型选择、生成参数和既有运行路径。启动器在原本地状态/日志目录中增加持久 `launch-<port>.lock`；请保留该文件，不要在服务可能持锁时复制或替换它。

先一致备份当前数据库（包含已提交 WAL）、媒体和配置，确认 UI 与 ComfyUI 两个写入端空闲并停止；同时更新独立源码和已安装扩展，从 `v0.2.1` 重建 `index.html`，通过原入口启动。确认两个构建身份一致，再测试真实文本/图片停止和重试。请阅读[协调升级要求](https://github.com/ThineLord/localgpt/blob/v0.2.1/docs/APP03_RECOVERY.md)；生成锁与本次启动锁是不同的文件，也必须保持原位。

回退时停止两端并先保存备份之后产生的新活动，不要用旧数据库覆盖新数据。发布标签不可重定向，后续修正使用新的补丁版本。
