# LocalGPT 0.1.0

Released: 2026-11-09

[English](https://github.com/ThineLord/localgpt/blob/v0.1.0/docs/releases/0.1.0.md) · [简体中文](https://github.com/ThineLord/localgpt/blob/v0.1.0/docs/releases/0.1.0.zh-CN.md)

## What changed

This is the first versioned source release of LocalGPT, based on the existing main application at `d4520a3`. It introduces a concise project home, separate English and Chinese user/agent guides, organized historical records, and an explicit release workflow.

The application baseline already includes local chat, ComfyUI image generation/editing, projects, saved memory, gallery, drafts, Chinese/English and appearance settings. This release makes no runtime behavior changes.

## Version management

`VERSION.txt` is the canonical source version. Future releases update the changelog and bilingual release notes, receive independent native subagent review and merge, and publish an immutable `vMAJOR.MINOR.PATCH` tag at the reviewed merge commit. Codex coordinates; no bots or cloud agents are part of this workflow.

## Compatibility and upgrading

Runtime source remains in `work/chat-sidebar/`. Existing launchers, API paths, database paths, browser storage, local model configuration and data directories are unchanged. No schema migration or restart is required for this documentation-only release. Existing installations do not automatically change when this source release is published.

For a new checkout, follow the [user guide](https://github.com/ThineLord/localgpt/blob/v0.1.0/docs/user-guide.md). For an existing checkout, inspect local changes before fetching/switching tags; do not switch the files of a running service as casual cleanup.

## Validation and limitations

Release preparation checks version consistency, documentation links, generated-page reproducibility, staged source and reachable history. The PR records the actual local checks and review for its exact head. Publication is separate from deployment and does not establish fresh real-model or production acceptance.

Pending [PR #26](https://github.com/ThineLord/localgpt/pull/26), including interrupted-generation recovery, is excluded and retains its own acceptance gates. Models and external local services are not bundled. Historical acceptance documents are provenance only.
