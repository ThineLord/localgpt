# LocalGPT 0.3.0

[简体中文](https://github.com/ThineLord/localgpt/blob/v0.3.0/docs/releases/0.3.0.zh-CN.md) · [Changelog](https://github.com/ThineLord/localgpt/blob/v0.3.0/docs/CHANGELOG.md)

## Dynamic wallpapers

Open **Settings → Appearance** and choose **Graphite**, **Starry Night** or **Water Lilies**. Each is drawn locally from tiny shaded cubes that rise and settle. Use the motion control to pause or resume the selected scene, or choose **Off** to return to the plain background. Wallpaper starts off. Each browser remembers its own selection and pause setting. Animation suspends in background tabs and respects the system’s reduced-motion preference.

## Other changes since 0.2.1

Regenerating an answer uses the history preceding that turn and replaces the answer in place. Stopped replies keep their partial output. The composer regains focus when a turn ends. Turning off global memory asks for confirmation and preserves saved entries. This release also includes improvements to generation settings on smaller screens, project creation, English labels and the bilingual repository guides.

## Upgrade and rollback

The browser draws these wallpapers without downloading artwork or calling a model. Wallpaper preferences live in the browser. On first startup the release adds three columns to the messages table for regeneration: attempt_started, attempt (default 1) and regenerate_key. Existing messages retain their content and use their creation time when no attempt start is stored. Configuration paths and model settings stay the same. Before upgrading, stop both writers when idle and back up the database with committed WAL data, media, configuration and installed extension. Update the standalone checkout and the ComfyUI extension together, rebuild the page from the tag, and verify both services report the release commit. See the [coordinated upgrade guide](https://github.com/ThineLord/localgpt/blob/v0.3.0/docs/reference/recovery.md).

To roll back, preserve any newer user activity, stop both writers and switch both code installations back together. Retain the current database and media, and verify compatibility on a copy before using the older writers. Animation smoothness depends on the device and viewport. Model inference is separate from wallpaper testing.
