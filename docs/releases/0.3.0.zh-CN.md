# LocalGPT 0.3.0

[English](https://github.com/ThineLord/localgpt/blob/v0.3.0/docs/releases/0.3.0.md) · [更新记录](https://github.com/ThineLord/localgpt/blob/v0.3.0/docs/CHANGELOG.md)

## 动态壁纸

进入 **设置 → 外观**，选择 **黑白灰**、**星月夜** 或 **睡莲**。三款壁纸都由浏览器在本地绘制，细小的立方体会成组浮起再落下。点击「暂停壁纸动效」可以保留当前壁纸，点击「继续壁纸动效」可以恢复动画。选择「无壁纸」即可回到原来的纯色背景。壁纸默认关闭，每个浏览器分别记住选择和暂停状态。切到后台或开启系统的减少动态效果时，动画会停止。

## 自 0.2.1 以来的其他更新

重新生成回答时，只使用该轮之前的对话，并在原位替换回答。停止生成会保留已经显示的内容，一轮结束后光标回到输入框。关闭全局记忆前会要求确认，已有记忆会保留。本版也改进了较小屏幕上的生成设置、项目创建、英文界面文字和双语仓库指南。

## 升级与回退

绘制壁纸无需下载画作或调用模型。壁纸偏好保存在浏览器内。首次启动时，数据库会在 messages 表增加三列，用于重新生成回答：attempt_started、attempt（默认值为 1）和 regenerate_key。已有消息保留原内容，缺少本次尝试的开始时间时使用原创建时间。配置路径和模型设置沿用原值。升级前请在空闲时停止独立界面和 ComfyUI 两个写入端，备份包含已提交 WAL 数据的数据库、媒体、配置和已安装的扩展。同步更新独立界面源码和 ComfyUI 扩展，从版本标签重新构建页面，再核对两端报告的版本和提交。[双端升级说明](https://github.com/ThineLord/localgpt/blob/v0.3.0/docs/reference/recovery.md)

回退前请先保留升级后的新活动，停止两个写入端，再同步切回两端代码，保留当前数据库和媒体，并在副本上验证旧版写入端兼容性后再使用。动效流畅度取决于设备和窗口大小。模型推理与壁纸测试分别验收。
