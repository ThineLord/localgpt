# LocalGPT 0.3.1

[English](https://github.com/ThineLord/localgpt/blob/v0.3.1/docs/releases/0.3.1.md) · [更新记录](https://github.com/ThineLord/localgpt/blob/v0.3.1/docs/CHANGELOG.md)

## 自 0.3.0 以来的改进

- 创建或重命名项目时，按回车确认输入法候选词仍会保留编辑框。切换项目后，即使较早的刷新迟到，标题和编辑操作仍对应选中的项目。
- 草稿写入失败或与另一窗口冲突时，同一标签页可以恢复未发送的输入。当前聊天被另一窗口永久删除后，未发送的文字会单独显示，便于复制。剩余聊天保留自己的草稿。
- 新草稿取得聊天编号后，已选的参考图仍能附到原聊天。若成功切到其他聊天，目标草稿保持原样；如果打开失败，原聊天仍可接收已上传的图片。
- 行内代码保留乘号、文件通配符等字面星号。Word 来源预览和检索会保留制表符与软换行。重新上传完全相同的 DOCX，可修复旧的提取文本，并保留来源编号和原始字节。

## 依赖与验证范围

PDF 读取采用 pypdf 6.x，最低为 6.21.4。Python 3.11 及以上使用含上游图像解码安全修复的 Pillow 13。为兼容 Python 3.10，此环境沿用 Pillow 12.3.0，缺少 Pillow 13 的上游修复。处理不受信任的文件时，建议使用 Python 3.11 或以上。头像校验和实际解码都只选择声明的 PNG、JPEG 或 WebP 格式。验收使用本地合成服务及 Chromium；真实模型推理与实体输入法需要另行测试。

## 升级与回滚

SQLite 结构、API 路径及模型配置保持兼容。浏览器草稿恢复限于同一标签页，切换版本或关闭标签页前请先保存。升级前在空闲时停止两个写入端，备份数据库及已提交的 WAL 数据、媒体、配置和扩展，然后把两处代码一起切到本标签，安装对应依赖并重新构建页面。若需回滚，请保留升级后的新数据，将两个写入端一起切回 v0.3.0，安装该版本的依赖，并先在副本上验证。[协调升级指南](https://github.com/ThineLord/localgpt/blob/v0.3.1/docs/reference/recovery.md)
