# LocalGPT 0.2.1

[中文发布说明](https://github.com/ThineLord/localgpt/blob/v0.2.1/docs/releases/0.2.1.zh-CN.md) · [Changelog](https://github.com/ThineLord/localgpt/blob/v0.2.1/CHANGELOG.md)

Released 2026-11-09. This patch updates runtime source; publishing it does not deploy an installation or bundle models.

## Fixes

- **Stop feedback follows the task.** The waiting notice clears when its chat/image generation reaches a terminal state. A late HTTP acknowledgement cannot bring it back. Another chat, a new task or an unrelated error keeps its own feedback. Existing stopped output, image interruption records and explicit retry behavior are preserved.
- **Slow startup remains pending.** The launcher waits for readiness for up to 120 seconds by default. A live process that needs longer is reported as still starting in the background, without a failure or false running claim. Run the launcher again to check that process. A per-port POSIX file lease is inherited by the service, preventing duplicate starts before port binding even if the original launcher exits. `--wait-seconds` changes the foreground wait budget; it does not cancel startup. Genuine process exit, occupied ports and mismatched services/checkouts still produce errors. Browser opening requires verified readiness.

## Validation

The current synthetic suite includes delayed stop acknowledgements, terminal-state feedback, unrelated stop errors, and 12 launcher regressions using isolated temporary processes and fake clocks. Launcher cases cover readiness beyond the previous 15-second window, pending output, concurrent/repeated launchers, parent exit, child failure and foreign-service protection. Negative controls with the previous implementations reproduce both regressions.

Run `.venv/bin/python tools/validate.py --setup` in a fresh virtual environment, or omit `--setup` after installation. Release acceptance runs the complete suite on the exact merged commit. Local real-model regression is a separate installation check; synthetic passes do not establish model quality, image latency, physical power-loss recovery or system-login autostart. No paid CI or cloud inference is configured by this release.

## Upgrade

No application data schema, model choice, generation parameters or configured runtime paths change from 0.2.0. The launcher adds a persistent `launch-<port>.lock` beside its existing local state/log files; leave this lock in place and do not copy or replace it while a service may hold it.

Back up the current database consistently, including committed WAL state, media and configuration. Quiesce both UI and ComfyUI writers, update the standalone source and installed extension together, rebuild `index.html` from `v0.2.1`, and restart through the existing launcher. Verify both build identities and test real text/image Stop and Retry before resuming normal use. Read the [coordinated upgrade requirements](https://github.com/ThineLord/localgpt/blob/v0.2.1/docs/APP03_RECOVERY.md); the generation lock is distinct from the new startup lease and must also remain intact.

For rollback, stop both writers and preserve all activity created since the backup. Do not overwrite newer user data with the pre-upgrade database. Never retarget a release tag; corrections use another patch version.
