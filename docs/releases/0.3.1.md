# LocalGPT 0.3.1

[简体中文](https://github.com/ThineLord/localgpt/blob/v0.3.1/docs/releases/0.3.1.zh-CN.md) · [Changelog](https://github.com/ThineLord/localgpt/blob/v0.3.1/docs/CHANGELOG.md)

## Changes since 0.3.0

- Confirming an IME candidate while creating or renaming a project leaves the editor open. Opening a different project keeps its title and editing target even if earlier refreshes arrive late.
- A tab can recover unsent input after a failed draft write or a conflicting edit. If another window permanently removes the open chat, a separate notice keeps unsent text available to copy. The surviving chat keeps its own draft.
- Reference-image uploads follow the original composer when a new draft acquires a chat ID. A successful switch to another chat leaves its draft intact. If the switch fails, the original composer can still accept the completed upload.
- Inline code preserves literal asterisks, including multiplication and file globs. DOCX sources retain tabs and soft line breaks in previews and retrieval. Re-upload an identical Word file to repair an older extraction in place with its original ID and bytes.

## Dependencies and validation limits

The PDF reader now requires pypdf 6.21.4 or later in the 6.x series. Python 3.11+ installs Pillow 13, which includes upstream image-decoder security fixes. Python 3.10 remains compatible using Pillow 12.3.0, which lacks those fixes. Prefer Python 3.11+ for processing untrusted files. The avatar endpoint limits decoder selection to the declared PNG, JPEG or WebP format on both paths. Validation uses synthetic local services and Chromium. Model inference and physical input methods require a separate live check.

## Upgrade and rollback

The SQLite schema, API paths and model configuration are unchanged. Browser draft recovery is scoped to the same tab. Save any pending drafts before switching versions or closing the tab. Before upgrading an installation, stop both writers when idle, back up the database and committed WAL data, media, configuration and extension, then update both code installations to this tag, install the declared dependencies and rebuild the page. To roll back, keep any newer user activity, switch both writers back to v0.3.0 together and use that release's dependencies. Verify on a copy before using the older writers. See the [coordinated upgrade guide](https://github.com/ThineLord/localgpt/blob/v0.3.1/docs/reference/recovery.md).
